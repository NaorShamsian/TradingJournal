יומן מסחר שמתמלא לבד מ-MetaTrader 5

המערכת מושכת את כל העסקאות שלך מ-MT5, שומרת אותן במסד נתונים משלך, מאחדת פוזיציות צמודות לעסקה אחת, ומציגה כל עסקה על גרף נרות עם חץ כניסה וחץ יציאה. המדריך מסביר איך להתקין, לחבר את החשבון ולהשתמש בכל דף.

WIN +$389.15 LOSS −$77.83 מאוחד · 4 פוז׳ XAUUSD.m · M15

מה צריך לפני שמתחילים

הכל חינמי. ההתקנה לוקחת בערך 20 דקות, פעם אחת.

  • מחשב Windowsספריית ה-Python של MT5 עובדת רק על Windows.
  • MetaTrader 5 למחשבמותקן, פתוח ומחובר לחשבון שלך.
  • Node.js 18 ומעלהמ-nodejs.org, גרסת LTS.
  • Python 3.8 ומעלה (64-bit)בהתקנה סמן Add python.exe to PATH.
  • Gitמ-git-scm.com, להורדת הפרויקט ולעדכונים.
  • חשבון MongoDB Atlasהמסד שבו נשמרות העסקאות שלך. התוכנית החינמית (M0) מספיקה.

התקנה חד-פעמית

לפי הסדר. את הפקודות מריצים בחלון Command Prompt או PowerShell.

  1. יצירת מסד נתונים ב-MongoDB Atlas

    • היכנס ל-mongodb.com/cloud/atlas וצור Cluster חינמי (M0).
    • תחת Database Access צור משתמש DB עם סיסמה, והרשאת Read and write to any database.
    • תחת Network Access לחץ Add Current IP Address.
    • חזור ל-Cluster, לחץ Connect ← Drivers והעתק את מחרוזת החיבור.

    חשוב: גם אם נכנסת ל-Atlas עם חשבון גוגל, החיבור מהקוד משתמש במשתמש ה-DB שיצרת בשלב הזה ובסיסמה שלו. אם שכחת אותה, ב-Database Access לוחצים Edit ← Edit Password וקובעים חדשה. עדיף סיסמה עם אותיות ומספרים בלבד.

  2. הורדת הפרויקט

    git clone https://github.com/NaorShamsian/TradingJournal.git
cd TradingJournal

  3. הגדרת השרת (backend)

    cd backend
npm install
copy .env.example .env

    פתח את הקובץ backend\.env בעורך טקסט ושים את מחרוזת החיבור בשורה MONGO_URI:

    MONGO_URI=mongodb+srv://USER:PASSWORD@cluster0.xxxxx.mongodb.net/trading_journal?retryWrites=true&w=majority
    • החלף את <db_password> בסיסמה בלי הסוגריים < >.
    • הוסף /trading_journal אחרי .mongodb.net ולפני ה-?.
    • אם יש בסיסמה תווים מיוחדים, קודד אותם: @=%40, #=%23, :=%3A, /=%2F.

  4. התקנת ספריות ה-Python

    cd ..\sync
pip install -r requirements.txt

    זה מתקין את הספרייה MetaTrader5, שדרכה המערכת מדברת עם תוכנת MT5.

  5. הגדרת האתר (frontend)

    cd ..\frontend
npm install
copy .env.example .env

    בקובץ הזה אין צורך לשנות כלום.

הפעלה יומיומית

בכל פעם שרוצים לעבוד עם היומן.

  1. פתח את MetaTrader 5

    התוכנה צריכה להיות פתוחה ומחוברת כדי שעסקאות חדשות ייכנסו. ההיסטוריה שכבר נשמרה זמינה גם כשהיא סגורה.

  2. הפעל את השרת (חלון ראשון)

    cd TradingJournal\backend
npm run dev

    כשהכל תקין יופיע MongoDB Connected ואחריו Server running on port 5000.

  3. הפעל את האתר (חלון שני)

    cd TradingJournal\frontend
npm run dev

  4. פתח בדפדפן

    היכנס ל-http://localhost:5173. את שני החלונות משאירים פתוחים כל זמן העבודה.

חיבור חשבון MT5

פעם אחת לכל חשבון. אפשר לחבר כמה חשבונות ולעבור ביניהם.

  1. פתח את תפריט החשבונות

    בתחתית התפריט הצדדי לחץ על כרטיס החשבון, ואז על הוספת חשבון.

  2. מלא את הפרטים

    • מספר חשבון (Login) וסיסמה.
    • שרת: בדיוק כמו שמופיע ב-MT5, למשל JustMarkets-Live3. ב-MT5 זה מופיע תחת File ← Login to Trade Account.
    • יתרת בסיס ואחוז סיכון: מהם מחושב גודל ה-1R. אפשר לשנות אותם אחר כך.
    • עומק היסטוריה: כמה אחורה לייבא. ברירת המחדל היא כל ההיסטוריה.

    מומלץ: השתמש בסיסמת המשקיע (Investor password) של החשבון, אם הברוקר נותן כזו. היא מאפשרת רק לקרוא היסטוריה ולא לפתוח עסקאות, וזה כל מה שהיומן צריך.

  3. לחץ "שמור חשבון"

    המערכת מתחברת ל-MT5, מוודאת שהפרטים נכונים ומייבאת את כל ההיסטוריה. זה לוקח בין כמה שניות לחצי דקה. מאותו רגע עסקאות חדשות נכנסות אוטומטית כל דקה.

מדריך לאתר

מה יש בכל דף ומה אפשר לעשות בו. השפה (עברית/אנגלית) ומצב כהה/בהיר מתחלפים בכפתורים בפינה העליונה.

לוח בקרה /

  • בחירת תקופה: שבוע, חודש, רבעון, שנה או הכל. כל הנתונים בדף מתעדכנים לפיה.
  • פרטי התקופה: יתרת הפתיחה בתחילת התקופה, יתרת הסגירה היום, רווח מהמסחר בדולרים ובאחוזים, והפקדות ומשיכות. היתרות מחושבות מההיסטוריה האמיתית ב-MT5.
  • נקודת איזון: ברירת המחדל היא יתרת הפתיחה של התקופה. לחיצה על הסכום מאפשרת לקבוע ערך אחר, ו"חזור לאוטומטי" מחזיר את ברירת המחדל.
  • עקומת הון: ירוקה מעל נקודת האיזון ואדומה מתחתיה, עם קו "מכאן ברווח" והתאריך שממנו אתה ברווח ברציפות. המתג "רווח ממסחר / יתרה בפועל" קובע אם הפקדות ומשיכות נכללות בעקומה.
  • רווח יומי: עמודה ירוקה ליום רווחי ואדומה ליום מפסיד.

יומן עסקאות /trades

  • כל עסקה מוצגת בכרטיס ירוק (רווח) או אדום (הפסד).
  • איחוד חכם: פוזיציות באותו סימבול ובאותו כיוון שנפתחו כשקודמת עוד הייתה פתוחה, או עד 5 דקות אחריה, מוצגות כעסקה אחת עם התג מאוחד · 4 פוז׳. הרווח והנפח הם הסכום של כל הפוזיציות.
  • המתג "עסקאות מאוחדות / כל פוזיציה בנפרד" מראה את הנתונים המקוריים מ-MT5.
  • יש סינון לפי סימבול, אסטרטגיה, סשן, תוצאה ותאריך, וחיפוש בהערות.

דף עסקה /trades/:id

  • גרף נרות מ-MT5 עם הנרות שלפני העסקה, בזמן שהיא פתוחה ואחריה:
▲ כניסת BUY ▼ כניסת SELL ▼▲ יציאה ברווח ▼▲ יציאה בהפסד קו מקווקו = מסלול כל פוזיציה · קווי SL ו-TP
  • הטיים-פריים נבחר אוטומטית לפי אורך העסקה. אפשר להחליף ל-M1, M5, M15, H1 או H4. בפעם הראשונה MT5 צריך להיות פתוח, ואחרי זה הגרף נשמר וזמין גם בלעדיו.
  • בעסקה מאוחדת יש טבלה של כל הפוזיציות: זמן ומחיר כניסה ויציאה, ורווח.
  • יומן: אסטרטגיה, סשן, רגש, טעויות, ציון עצמי, סיבות כניסה ויציאה והערות. צילומי מסך מדביקים עם Ctrl+V. השמירה חלה על כל הפוזיציות של העסקה.

לוח שנה ואנליזה /calendar · /analytics

  • לוח שנה: כל יום צבוע לפי הרווח שלו. לחיצה על יום מציגה את העסקאות שלו.
  • אנליזה: ביצועים לפי סימבול, סשן, אסטרטגיה ושעה ביום.

חשבון וסיכון /account

  • יתרת בסיס: ידנית, או אוטומטית לפי ההפקדה הראשונה או ההפקדות נטו ב-MT5.
  • סיכון לעסקה: אפשר להזין באחוזים או ישירות כ-1R בדולרים, והשני מחושב לבד. גודל ה-R של כל עסקה באתר מחושב מזה.
  • נתונים חיים מ-MT5: יתרה, equity, הפקדות, משיכות ומינוף.
  • מצב החיבור ל-MongoDB, כמה עסקאות שמורות, מתי היה הסנכרון האחרון, וכפתור "סנכרן עכשיו".

הגדרות /settings

  • רשימת האסטרטגיות שמופיעה ביומן, ומטבע התצוגה.
  • איחוד עסקאות: אפשר לכבות את האיחוד, או לשנות את החלון (ברירת מחדל 5 דקות; 0 = לאחד רק פוזיציות חופפות).

פתרון תקלות

ההודעה שמופיעה, והפתרון.

הודעהמה לעשות
MetaTrader5 Python library is not installedהרץ pip install -r requirements.txt בתיקייה sync. אם יש לך כמה גרסאות Python, הגדר ב-backend\.env את PYTHON_PATH עם הנתיב המלא ל-python.exe.
bad auth : authentication failedהסיסמה ב-MONGO_URI שגויה. בדוק שהסרת את < > ושזו סיסמת משתמש ה-DB ולא סיסמת הכניסה ל-Atlas.
MongoDB connection error / Could not connect to any serversב-Atlas ← Network Access הוסף את ה-IP הנוכחי שלך. ה-IP משתנה לפעמים, למשל ברשת אחרת.
MT5 connection verification failedודא ש-MT5 פתוח ומחובר לאותו חשבון, ושהשרת והסיסמה הוקלדו בדיוק כמו ב-MT5.
Could not load the chartפתח את MT5 ולחץ על כפתור טיים-פריים כדי לנסות שוב. בעסקאות ישנות הגרף עובר לבד לטיים-פריים גדול יותר, כי הברוקר לא שומר נרות של דקה לאורך זמן.
העסקאות לא מופיעותבדוק שהחשבון הנכון מסומן כפעיל בתחתית התפריט. בדף "חשבון וסיכון" רואים כמה עסקאות שמורות ומה השגיאה האחרונה בסנכרון.
עסקה שמחקתי חזרההסנכרון בודק מחדש את 3 הימים האחרונים, ולכן עסקה שנמחקה מהתקופה הזו תיובא שוב. עסקאות ישנות יותר לא יחזרו.

אבטחה ופרטיות

  • כל אחד עם מסד נתונים משלו. העסקאות, ההערות ופרטי החשבון נשמרים ב-Atlas שלך בלבד.
  • סיסמת MT5 נשמרת במסד בלי הצפנה. לכן מומלץ להשתמש בסיסמת המשקיע (קריאה בלבד), ולא לשתף את גישת ה-Atlas עם אף אחד.
  • הקובץ .env הוא פרטי. הוא מוחרג מ-git ולא יעלה ל-GitHub. לא לשלוח אותו לאף אחד.
  • האתר רץ רק על המחשב שלך (localhost) ואין בו מסך כניסה. לא לפתוח את הפורטים 5000 או 5173 לאינטרנט.

עדכון לגרסה חדשה

כשיש שינויים חדשים ב-GitHub. סגור קודם את שני החלונות של השרת והאתר.

cd TradingJournal
git pull
cd backend && npm install && cd ..
cd frontend && npm install && cd ..
cd sync && pip install -r requirements.txt && cd ..

אחר כך מפעילים כרגיל, לפי הפעלה יומיומית. הנתונים שלך במסד לא נפגעים בעדכון.
