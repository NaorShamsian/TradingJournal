יומן מסחר שמתמלא לבד מ-MetaTrader 5

המערכת מושכת את כל העסקאות שלך מ-MT5 ושומרת אותן במסד נתונים משלך. היא מאחדת פוזיציות צמודות לעסקה אחת, ומציגה כל עסקה על גרף נרות עם חץ כניסה וחץ יציאה.

המדריך מסביר איך להתקין, לחבר את החשבון ולהשתמש בכל דף.

WIN +$389.15 LOSS −$77.83 מאוחד · 4 פוזיציות XAUUSD.m · M15

מה צריך לפני שמתחילים

הכל חינמי. ההתקנה לוקחת בערך 20 דקות, ועושים אותה פעם אחת.

  • מחשב Windowsספריית ה-Python של MT5 עובדת רק על Windows.
  • תוכנת MetaTrader 5מותקנת במחשב, פתוחה ומחוברת לחשבון שלך.
  • Node.js גרסה 18 ומעלהמהאתר nodejs.org, גרסת LTS.
  • Python גרסה 3.8 ומעלהגרסת 64 ביט. בזמן ההתקנה סמנו את Add python.exe to PATH.
  • Gitמהאתר git-scm.com. משמש להורדת הפרויקט ולעדכונים.
  • חשבון MongoDB Atlasהמסד שבו נשמרות העסקאות שלך. התוכנית החינמית מספיקה.

התקנה חד-פעמית

לפי הסדר. את הפקודות מריצים בחלון Command Prompt או PowerShell.

  1. יצירת מסד נתונים ב-MongoDB Atlas

    • היכנסו ל-mongodb.com/cloud/atlas וצרו Cluster חינמי.
    • במסך Database Access: צרו משתמש עם סיסמה, ותנו לו הרשאת קריאה וכתיבה לכל המסדים.
    • במסך Network Access: לחצו Add Current IP Address.
    • חזרו ל-Cluster, לחצו Connect ואז Drivers, והעתיקו את מחרוזת החיבור.
    שימו לב

    גם אם נכנסתם ל-Atlas עם חשבון גוגל, החיבור מהקוד משתמש במשתמש שיצרתם במסך Database Access ובסיסמה שלו. שכחתם אותה? לחצו שם על Edit ואז Edit Password, וקבעו חדשה. עדיף סיסמה עם אותיות ומספרים בלבד.

  2. הורדת הפרויקט

    פקודה
    git clone https://github.com/NaorShamsian/TradingJournal.git
cd TradingJournal

  3. הגדרת השרת

    פקודה
    cd backend
npm install
copy .env.example .env

    פתחו את הקובץ backend\.env בעורך טקסט, ושימו את מחרוזת החיבור בשורה של MONGO_URI. היא צריכה להיראות כך:

    דוגמה
    MONGO_URI=mongodb+srv://USER:PASSWORD@cluster0.xxxxx.mongodb.net/trading_journal?retryWrites=true&w=majority
    • במקום <db_password> כתבו את הסיסמה, בלי הסימנים < ו->.
    • הוסיפו /trading_journal מיד אחרי .mongodb.net.
    • אם יש בסיסמה תווים מיוחדים, החליפו אותם: @ ב-%40, # ב-%23, : ב-%3A, / ב-%2F.

  4. התקנת ספריות ה-Python

    פקודה
    cd ..\sync
pip install -r requirements.txt

    זה מתקין את הספרייה שדרכה המערכת מדברת עם תוכנת MT5.

  5. הגדרת האתר

    פקודה
    cd ..\frontend
npm install
copy .env.example .env

    בקובץ הזה לא צריך לשנות כלום.

הפעלה יומיומית

בכל פעם שרוצים לעבוד עם היומן.

  1. פתחו את MetaTrader 5

    התוכנה צריכה להיות פתוחה ומחוברת כדי שעסקאות חדשות ייכנסו. היסטוריה שכבר נשמרה זמינה גם כשהיא סגורה.

  2. הפעילו את השרת, בחלון ראשון

    פקודה
    cd TradingJournal\backend
npm run dev

    כשהכל תקין יופיעו השורות MongoDB Connected ו-Server running on port 5000.

  3. הפעילו את האתר, בחלון שני

    פקודה
    cd TradingJournal\frontend
npm run dev

  4. פתחו בדפדפן

    היכנסו לכתובת http://localhost:5173. את שני החלונות משאירים פתוחים כל זמן העבודה.

חיבור חשבון MT5

פעם אחת לכל חשבון. אפשר לחבר כמה חשבונות ולעבור ביניהם.

  1. פתחו את תפריט החשבונות

    בתחתית התפריט הצדדי לחצו על כרטיס החשבון, ואז על הוספת חשבון.

  2. מלאו את הפרטים

    • מספר חשבון וסיסמה, כמו שמתחברים ב-MT5.
    • שרת: בדיוק כמו שמופיע ב-MT5, למשל JustMarkets-Live3.
    • יתרת בסיס ואחוז סיכון: מהם מחושב גודל ה-1R. אפשר לשנות אחר כך.
    • עומק היסטוריה: כמה אחורה לייבא. ברירת המחדל היא כל ההיסטוריה.
    מומלץ

    השתמשו בסיסמת המשקיע של החשבון (Investor password), אם הברוקר נותן כזו. היא מאפשרת רק לקרוא היסטוריה ולא לפתוח עסקאות, וזה כל מה שהיומן צריך.

  3. לחצו "שמור חשבון"

    המערכת מתחברת ל-MT5, בודקת שהפרטים נכונים ומייבאת את כל ההיסטוריה. זה לוקח בין כמה שניות לחצי דקה.

    מאותו רגע עסקאות חדשות נכנסות אוטומטית, פעם בדקה.

מדריך לאתר

מה יש בכל דף ומה אפשר לעשות בו. השפה ומצב כהה או בהיר מתחלפים בכפתורים בפינה העליונה.

לוח בקרה

  • בחירת תקופה: שבוע, חודש, רבעון, שנה או הכל. כל הנתונים בדף מתעדכנים לפיה.
  • פרטי התקופה: יתרת הפתיחה בתחילת התקופה, יתרת הסגירה היום, הרווח מהמסחר בדולרים ובאחוזים, והפקדות ומשיכות. היתרות מחושבות מההיסטוריה האמיתית ב-MT5.
  • נקודת איזון: ברירת המחדל היא יתרת הפתיחה של התקופה. לחיצה על הסכום מאפשרת לקבוע ערך אחר, ו"חזור לאוטומטי" מבטל את השינוי.
  • עקומת הון: ירוקה מעל נקודת האיזון ואדומה מתחתיה. מסומן עליה התאריך שממנו אתם ברווח ברציפות. המתג "רווח ממסחר / יתרה בפועל" קובע אם הפקדות ומשיכות נכללות.
  • רווח יומי: עמודה ירוקה ליום רווחי ואדומה ליום מפסיד.

יומן עסקאות

  • כל עסקה מוצגת בכרטיס ירוק אם הרוויחה, או אדום אם הפסידה.
  • איחוד חכם: כמה פוזיציות באותו סימבול ובאותו כיוון, שנפתחו כשהקודמת עוד הייתה פתוחה או עד 5 דקות אחריה, מוצגות כעסקה אחת עם התג מאוחד · 4 פוזיציות. הרווח והנפח הם הסכום של כולן.
  • המתג "עסקאות מאוחדות / כל פוזיציה בנפרד" מראה את הנתונים המקוריים מ-MT5.
  • אפשר לסנן לפי סימבול, אסטרטגיה, סשן, תוצאה ותאריך, ולחפש בהערות.

דף עסקה

לוחצים על "גרף ויומן" בכרטיס של עסקה. בראש הדף יש גרף נרות מ-MT5, עם הנרות שלפני העסקה, בזמן שהיא פתוחה ואחריה:

▲ כניסה בקנייה ▼ כניסה במכירה ▼▲ חץ יציאה ברווח ▼▲ חץ יציאה בהפסד קו מקווקו: מסלול כל פוזיציה קווים אופקיים: SL ו-TP
  • הטיים-פריים נבחר לבד לפי אורך העסקה, ואפשר להחליף אותו בכפתורים. בפעם הראשונה MT5 צריך להיות פתוח. אחרי זה הגרף נשמר וזמין גם בלעדיו.
  • בעסקה מאוחדת יש טבלה של כל הפוזיציות: מתי ובאיזה מחיר כל אחת נכנסה ויצאה, וכמה הרוויחה.
  • יומן: אסטרטגיה, סשן, רגש, טעויות, ציון עצמי, סיבות כניסה ויציאה והערות. צילום מסך מדביקים עם Ctrl+V. השמירה חלה על כל הפוזיציות של העסקה.

לוח שנה ואנליזה

  • לוח שנה: כל יום צבוע לפי הרווח שלו. לחיצה על יום מציגה את העסקאות שלו.
  • אנליזה: ביצועים לפי סימבול, סשן, אסטרטגיה ושעה ביום.

חשבון וסיכון

  • יתרת בסיס: ידנית, או אוטומטית לפי ההפקדה הראשונה או ההפקדות נטו ב-MT5.
  • סיכון לעסקה: באחוזים או ישירות כ-1R בדולרים, והשני מחושב לבד. ה-R של כל עסקה באתר מחושב מזה.
  • נתונים חיים מ-MT5: יתרה, הון, הפקדות, משיכות ומינוף.
  • מצב החיבור למסד הנתונים, כמה עסקאות שמורות, מתי היה הסנכרון האחרון, וכפתור "סנכרן עכשיו".

הגדרות

  • רשימת האסטרטגיות שמופיעה ביומן, ומטבע התצוגה.
  • איחוד עסקאות: אפשר לכבות אותו או לשנות את החלון. ברירת המחדל היא 5 דקות, ו-0 מאחד רק פוזיציות שהיו פתוחות באותו זמן.

פתרון תקלות

ההודעה שמופיעה, ומה לעשות.

MetaTrader5 Python library is not installed
הריצו pip install -r requirements.txt בתיקייה sync. אם מותקנות כמה גרסאות Python, הגדירו בקובץ backend\.env את PYTHON_PATH עם הנתיב המלא לקובץ python.exe.
bad auth : authentication failed
הסיסמה במחרוזת החיבור שגויה. ודאו שהסרתם את < ו->, ושזו הסיסמה של משתמש המסד ולא של הכניסה ל-Atlas.
MongoDB connection error
ב-Atlas, במסך Network Access, הוסיפו את כתובת ה-IP הנוכחית. היא משתנה לפעמים, למשל כשמתחברים מרשת אחרת.
MT5 connection verification failed
ודאו ש-MT5 פתוח ומחובר לאותו חשבון, ושהשרת והסיסמה הוקלדו בדיוק כמו ב-MT5.
Could not load the chart
פתחו את MT5 ולחצו על אחד מכפתורי הטיים-פריים כדי לנסות שוב. בעסקאות ישנות הגרף עובר לבד לטיים-פריים גדול יותר, כי הברוקר לא שומר נרות של דקה לאורך זמן.
העסקאות לא מופיעות
בדקו שהחשבון הנכון מסומן כפעיל בתחתית התפריט. בדף "חשבון וסיכון" רואים כמה עסקאות שמורות ומה השגיאה האחרונה בסנכרון.
עסקה שמחקתי חזרה
הסנכרון בודק מחדש את 3 הימים האחרונים, ולכן עסקה שנמחקה מהתקופה הזו תיובא שוב. עסקאות ישנות יותר לא יחזרו.

אבטחה ופרטיות

  • לכל אחד מסד נתונים משלו. העסקאות, ההערות ופרטי החשבון נשמרים רק ב-Atlas שלכם.
  • סיסמת MT5 נשמרת במסד בלי הצפנה. לכן מומלץ להשתמש בסיסמת המשקיע, שהיא לקריאה בלבד, ולא לשתף את הגישה ל-Atlas עם אף אחד.
  • הקובץ .env פרטי. הוא לא עולה ל-GitHub, ואין לשלוח אותו לאף אחד.
  • האתר רץ רק על המחשב שלכם ואין בו מסך כניסה. אל תפתחו את הפורטים 5000 ו-5173 לאינטרנט.

עדכון לגרסה חדשה

כשיש שינויים חדשים ב-GitHub. קודם סגרו את שני החלונות של השרת והאתר.

פקודה
cd TradingJournal
git pull
cd backend && npm install && cd ..
cd frontend && npm install && cd ..
cd sync && pip install -r requirements.txt && cd ..

אחר כך מפעילים כרגיל, לפי השלבים בהפעלה יומיומית. הנתונים שלכם במסד לא נפגעים בעדכון.
